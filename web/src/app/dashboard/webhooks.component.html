How to accept and verify a webhook

Verify the Standard Webhooks signature with your signing secret and the raw request body. Headers are webhook-id, webhook-timestamp, and webhook-signature. Reject stale requests, deduplicate the event ID, and return 2xx after durable acceptance.

Verification requests have type webhook.verification and include data.token. See the API reference for schemas.
