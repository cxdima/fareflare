# Production verification

Current checks are recorded in [website verification](WEBSITE_VERIFICATION.md) and
[collector and integration verification](RELEASE_VERIFICATION.md). Use the
[operations runbook](OPERATIONS.md) for installation-specific release and rollback
procedures.

Keep deployed image digests, account identifiers, state locations, and smoke-test
credentials in private operator records. Historical source revisions remain
available in Git; they are not configuration templates for a new installation.
